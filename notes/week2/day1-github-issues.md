## Important points regarding github issues:
- We can reference an issue in a commit message.
    `This commit is based on #4` where #4 is the issue ID on github
- If we specify the keyword fixes before an issue number than github will auto close the issue
- If we comment the commit id of a commit on any issue. Github will create a reference lint to the commit
